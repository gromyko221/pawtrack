Песочница: как двигать блоки

Правило номер один

Расположение задаётся родителю, а не детям. Хочешь выстроить три карточки в ряд — пишешь display: flex тому блоку, внутри которого они лежат. Это главная причина, по которой у новичков «ничего не двигается»: они пытаются командовать самим карточкам.

Дальше выбираешь одну из двух систем: flex — выстроить в линию (одно измерение), grid — разложить сеткой (два измерения).

8. Колонки разной ширины

Широкая, 2fr
Узкая, 1fr

Классический макет «контент + боковая колонка».

Что выбирать

flex — когда элементы в одну линию и их ширина зависит от содержимого: шапка, кнопки в ряд, подвал, иконка рядом с текстом.

grid — когда нужна сетка с одинаковыми ячейками: карточки, галереи, макет страницы целиком.

Не мучайся выбором. Возьми любую, посмотри на результат, при необходимости поменяй. На реальных сайтах они работают вместе: grid раскладывает карточки, а внутри каждой карточки flex расставляет содержимое.

Главный инструмент верстальщика

Нажми F12 на любой странице (или правый клик → «Просмотреть код»). Откроются инструменты разработчика: слева HTML, справа CSS выделенного элемента. Правила там можно менять прямо на живой странице — снимать галочки, править числа, и сразу видеть результат. Ничего не сломается, при обновлении всё вернётся.

Так делают все, каждый день. Подобрала значение в F12 — перенесла в свой style.css. Это быстрее, чем угадывать в редакторе.
